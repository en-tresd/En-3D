1) AUTHENTICATION

   > Habilitar > Guardar.  Pestana "Usuarios" > Agregar usuario (tu mail y contrasena).
   Authentication > Configuracion > Dominios autorizados: agregar tuusuario.github.io

2) FIRESTORE  (fotos, categorias, opciones del formulario y PEDIDOS)
   Firestore Database > Crear base de datos > modo produccion > Habilitar.
   Pestana "Reglas" > borrar todo > pegar esto > cambiar TU_MAIL@gmail.com
   por tu mail en minusculas (un solo lugar) > Publicar:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function esAdmin() {
      return request.auth != null
          && request.auth.token.email in ['TU_MAIL@gmail.com'];
    }
    match /photos/{foto} {
      allow read: if true;
      allow create: if esAdmin()
                    && (!('data' in request.resource.data)
                        || request.resource.data.data.size() < 900000);
      allow delete: if esAdmin();
    }
    match /settings/{doc} {
      allow read: if true;
      allow write: if esAdmin();
    }
    match /orders/{pedido} {
      allow read, write: if esAdmin();
    }
  }
}

3) STORAGE  (solo para VIDEOS; las fotos no lo necesitan)
   Storage > Comenzar. Firebase puede pedir pasar al plan Blaze (de pago por uso,
   con cuota gratis mensual; pide tarjeta). Si no queres eso, subi solo fotos.
   Pestana "Reglas" de Storage > borrar todo > pegar esto > cambiar el mail > Publicar:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /videos/{allPaths=**} {
      allow read: if true;
      allow create: if request.auth != null
                    && request.auth.token.email in ['TU_MAIL@gmail.com']
                    && request.resource.size < 50 * 1024 * 1024;
      allow delete: if request.auth != null
                    && request.auth.token.email in ['TU_MAIL@gmail.com'];
    }
  }
}

NOTA: si ya tenias las reglas publicadas, agrega el bloque  match /orders/{pedido}  de arriba
y volve a Publicar. Sin eso el boton "Pedidos" del admin da error de permiso.
